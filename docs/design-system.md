# Design system

Preserve the existing palette and conventions. Components reuse these tokens — add semantic aliases, not parallel values.

## Tokens

- Radii: `--radius-sm 8px`, `-md 10px`, `-lg 14px`, `-xl 18px`, pill.
- Shadows: neutral greys (`--shadow-sm/md/lg`, `--shadow-modal`). No colored glows.
- Type scale: 11/13/16/18/21/24/32/36 (`--text-xs`…`--text-brand`). Fonts: Inter (body), Poppins (brand/headings). Functional text ≥11px; display numerals use tabular figures and `-0.04em` tracking floor.
- Motion: `--ease-out cubic-bezier(0.23,1,0.32,1)` for entrances; `--ease-drawer` for sheets; `--ease-bounce` only for the welcome/login logo pop. Entrances 0.18–0.5s; tab glide 0.28s.

## Screen-scoped systems (Home · Wallet · QR · Rewards · Profile)

Home, Wallet, and QR define local aliases on their root (`--home-*`, `--wallet-*`, `--qr-*`) mapped to the palette above, so screens stay consistent without forking tokens. Rewards and Profile use the shared tokens directly (`--pf-gutter`, `--pf-ink` on Profile).

- **Shell + headings:** Home is the only branded destination (logo + wordmark + brand note + notifications). Root tabs EcoWallet, My QR, Rewards, and Profile carry a single contextual `.page-title-block h1` — no repeated masthead, no back arrow. Nested pages keep their compact back header.
- **Welcome & Auth (Welcome · Login · Register):** Editorial Eco-Tech experience with unified motion and token fidelity. The Welcome screen is a cinematic environmental composition built on `.wlc-scene`: an inline SVG field (`.wlc-art`) of topographic contours (`.wlc-contour`, drawn on with `stroke-dashoffset`), layered canopy silhouettes (`.wlc-canopy`), gradient light ribbons (`.wlc-ribbons`), a rounded recycling-loop motif (`.wlc-motif`), plus CSS light pools (`.wlc-glow-a/b`), a sweeping light pass (`.wlc-light`), three luminous motes (`.wlc-mote-*`) and a tiling grain texture (`assets/grain.png`). The existing `assets/logo.png` is the centerpiece — never redrawn or distorted — framed by a blooming halo (`.wlc-aura`), an orbiting rim (`.wlc-rim`) and a tap ripple (`.wlc-ripple`); the mark and wordmark share one box (`.welcome-mark`, `clamp(96px, 26vw, 118px)`) so the halo scales with it. Typography: uppercase lime eyebrow with a lime rule, Poppins headline (`clamp(28px, 8.2vw, 38px)`) with masked line reveals (`.wlc-line` / `.wlc-line-in`), lime-emphasised "into rewards." (`.wlc-em`) with a scaleX underline wash, and a 14.5px supporting EcoPoints line. Actions: white primary CTA (`.wlc-btn-start`, 56px min, press-down `translateY(2px) scale(0.975)`) and the secondary Reset Demo Data link. Entrance is a 5-stage ~1.8s choreography (scene → mark → environment → typography → CTA) that never blocks interaction; ambient motion after it is transform/opacity only. Touch: logo tap fires the ripple, pointer movement drives a light scene parallax (`--wlc-px` / `--wlc-py`) that eases back to rest. Login features a top brand gradient stripe, dedicated back navigation, emerald-focus inputs with 3px elevation, interactive password visibility eye toggle (open/closed SVG swap), and a polished collapsible prototype demo panel (`Explore Rikna`) with role-specific icons and active card selection highlight (`.selected-demo`). Register features a sticky header, icon-prefixed form inputs (`.reg-input-wrap`) with focus coupling, terms disclaimer, and resident signup. Auth navigation is a shared-mark handoff (`handoffTo`): the two screens cross-dissolve while a body-level clone of the mark flies into the incoming logo slot; the post-login exit stays a curtain lift (`.login-leaving`: −56px + fade 0.45s `var(--ease-out)`). Under `prefers-reduced-motion` the handoff becomes an instant swap and every welcome entrance collapses to a 0.2s fade with the masked lines and lime underline at their resting state. ## Components & rules

- Audit log rows use 16px vertical padding, inset borders between entries, 14px semibold action titles, 13px descriptions with 1.5 line-height, ≥12px timestamps with better contrast, semibold IDs, EcoPoints values in Rikna forest green, and a decorative clock icon. Text stays full-width and wraps within the card.

- Buttons: flat, 44px+ targets, press = `scale(0.98)` (+ dim on primary), visible `:focus-visible` ring.
- Iconography: existing 24px outline SVGs, 1.8 stroke. No emojis as icons.
- Dynamic text: insert via `textContent` / `replaceChildren`, never `innerHTML` interpolation.
- Motion: transform/opacity only; one authored entrance per flow; reduced motion = fade/instant, never zero comprehension.
- Layout: mobile 320–430px, no horizontal overflow, safe-area-aware nav, long content wraps.
- Horizontal rails: `overflow-x: auto`, `flex-wrap: nowrap`, `flex: 0 0 auto` children, hidden scrollbar, `overscroll-behavior-x: contain`, `scroll-padding` matching the container gutters, and no edge-fade overlays over interactive content (a clipped child is the scroll cue).
